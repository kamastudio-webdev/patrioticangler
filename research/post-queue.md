# Weekly post queue

One new post goes up each Thursday. The weekly run takes the **first unchecked item**,
writes it, and checks it off with the date and slug. If a week was missed, the next run
just takes the next unchecked item.

Items marked **(seasonal)** only make sense near their target date. If a seasonal item's
target date is more than 3 weeks in the past, mark it `[-] skipped (season passed)` and
take the next one.

When fewer than 4 unchecked items are left, the run adds 6 new ones at the bottom
(see `research/weekly-post-runbook.md`, step 9).

Format: `- [ ] target date | slug | category | hubs | angle`
